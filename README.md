## How Steal Works
Steal works by cycling through package managers and install commands until it finds the package you want to download. It can also download media files.

```
steal [ PACKAGE1 ] [ PACKAGE2 ]

steal [ URL1 ] [ URL2 ]

steal [ URL1 ] [ URL2 ] /home/you/custom
```

## Compatibility
* `Pacman` 
* `Paru`
* `Yay`
* `XBPS`
* `APT`
* `Flatpak`
* `YT-DLP`
* `Gallery-DL`
* `DOAS`

## How to Install
. Place `steal` in `/bin`

. Make the program executable

```
sudo chmod +x /bin/steal
```
